# crypto-ai-bot (full package)

This package contains a modular crypto trading bot skeleton with:
- data collection (Binance testnet)
- model training & prediction (scikit-learn RandomForest)
- executor with risk-manager (testnet by default)
- web dashboard (Flask)
- Telegram alerts hook
- OpenAI hook placeholder (optional)

Default mode: SIMULATION. Do NOT enable REAL mode until fully tested.

See DEPLOY_GUIDE.md for Railway/GitHub deploy steps and required environment variables.
